## Decciones

### A. Representacion obligatoria de los bits

| Código | Significado    |
| ------ | -------------- |
| 000    | Posición vacía |
| 001    | # (35)         |
| 010    | & (38)         |
| 011    | @ (64)         |
| 100    | ) (41)         |
| 101    | = (61)         |
| 110    | % (36)         |
| 111    |                |

### B. Representacion de tablero

Reglas prohiben crear extructuras de tablero con espacios adicionales con el propocito de alinear cada ficha a un byte, es decir, `unsigned char tablero[x][y]`, o cualquier array multidimencional queda prohibido por definicion (cada posicion es un paquete de bytes y no de 3 bist).

==unsigned char \*tablero  | con new y delete ==

#### Alternativas


unsigned int \*tablero 

unsigned long long \*tablero

> [!warning]
> Decartados por representar una catidad de bits demaciado grande. PARA REPRESENTACION DEL TABLERO
